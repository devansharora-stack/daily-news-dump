arXiv

arXiv
This research paper argues that current AI agent design actively impedes effective human oversight, and that the cognitive capacities required for human-in-the-loop monitoring are themselves degraded by extended AI use. For enterprises banking on 'human oversight' as their AI risk mitigation strategy, this is a direct challenge to conventional governance assumptions.
Poisoning Agentic Alpha: Adversarial Vulnerabilities in Multi-Agent Trading Systems
arXiv
Researchers demonstrate that LLM-based multi-agent trading systems — now moving from prototypes to live deployments controlling real assets — can be compromised through inter-agent communication channels. A single corrupted signal can propagate to final trading decisions, translating directly into realized financial losses. Critical reading for any financial institution deploying agentic AI.

Paritok-4B: Intent-Conditioned Context Compression for Coding Agents
arXiv
Researchers present Paritok-4B, a compression tool that reduces the token cost of coding agents by selectively extracting relevant code spans rather than re-sending entire files each turn. For enterprises running AI coding agents at scale, this directly addresses 'token anxiety' — the ballooning inference costs that can make agentic AI economically unviable.
